# 信号规格 v1（P1）

> 状态：**草稿，待用户确认**。确认后定稿，之后不用回测调参；要改须先改本文并注明版本。
> 适用：股票池中 `tier` 为 core / extended 的股票（benchmark 只做参照，不出信号）。

## 1. 基本约定

| 项目 | 约定 |
| --- | --- |
| 数据 | `bars_daily`，拆股复权（Massive `adjusted=true`），未做分红复权 |
| 计算时点 | 每个交易日收盘后、当天日线入库后计算一次（只用收盘数据，不用盘中） |
| 周线 | 由日线合成：周一至周五，开=首日开，高=最高，低=最低，收=末日收，量=合计。**只用已走完的周**：扫描日为周五（或之后的周）时，本周算走完；周五休市的周到下周一才算走完 |
| 最少数据 | 不足 60 根日线：不计算；60–249 根：不出依赖分位数的信号；≥ 250 根：全部信号 |
| 方向 | `bull` 看多 / `bear` 看空 |
| 强度 | 每个信号 1–3 分 |
| 有效期 | 日线信号触发后 **3 个交易日**内有效（当天 + 前 2 天）；周线信号 **5 个交易日**内有效。同一信号在有效期内多次触发只算一次（取最近一次） |

### 1.1 自身分位数（自适应阈值）

所有「高/低」判断都用该股**自己**的历史分布，不用全市场固定值：

```
pct(x, t) = 过去 250 个交易日（t-250 … t-1，不含当天）中严格小于 x_t 的个数 ÷ 有效个数
```

- 取值 0–1。`pct ≤ 0.10` 叫「到自身 10% 分位」，`pct ≥ 0.90` 叫「到自身 90% 分位」。
- 窗口内有效值不足 120 个时 `pct` 记为空，相关信号不触发。
- 存入 `indicators_daily.pct`，用于界面上「为什么触发」的说明。

## 2. 指标定义

参数一律固定，与 TradingView 默认一致，方便对照。

| 名称（`indicators_daily.name`） | 公式 | 参数 |
| --- | --- | --- |
| `sma20` / `sma50` / `sma200` | 收盘价简单均线 | 20 / 50 / 200 |
| `ema12` / `ema26` | 指数均线，α = 2/(n+1)，首值用前 n 根 SMA | 12 / 26 |
| `macd` / `macd_signal` / `macd_hist` | macd = ema12 − ema26；signal = macd 的 9 日 EMA；hist = macd − signal | 12, 26, 9 |
| `rsi14` | Wilder RSI：涨跌幅用 RMA（α = 1/14）平滑 | 14 |
| `atr14` | TR = max(高−低, \|高−昨收\|, \|低−昨收\|)，ATR = TR 的 RMA | 14 |
| `bb_upper` / `bb_lower` / `bb_width` | 中轨 = sma20，上下轨 = 中轨 ± 2 × 总体标准差（20 日）；width = (上 − 下) ÷ 中轨 | 20, 2 |
| `st_line` / `st_dir` | SuperTrend：基准 = (高+低)/2，上轨 = 基准 + 3×ATR(10)，下轨 = 基准 − 3×ATR(10)，按经典规则递推；dir = +1 多 / −1 空 | ATR 10，倍数 3 |
| `vol_ratio` | 当天量 ÷ 前 20 日均量（不含当天） | 20 |
| `obv` | 收涨加当天量，收跌减当天量，平盘不变，累计 | — |
| `tr_ratio` | 当天 TR ÷ 昨天 ATR14 | — |
| `hi_52w` / `lo_52w` | 前 251 个交易日（不含当天）的最高价 / 最低价 | 251 |
| `ma50_dev` | (收盘 − sma50) ÷ atr14，单位为「倍 ATR」 | — |
| `ret20` | 20 日涨跌幅 = 收盘 ÷ 20 天前收盘 − 1 | 20 |

周线指标（名称前缀 `w_`）：`w_sma10`、`w_sma30`、`w_macd`、`w_macd_signal`、`w_st_dir`，公式同上，用周线计算。

### 2.1 摆动点（背离用）

摆动低点：某根 K 线的最低价是它左右各 5 根中最低的。摆动高点同理（最高价）。摆动点要等右侧 5 根走完才确认，所以**背离信号最早在摆动点之后第 5 天触发**。

## 3. 周线趋势状态（定方向，本身不是信号）

| 状态 | 条件（最近一根已走完的周线） |
| --- | --- |
| 上升 `up` | 周收 > w_sma10 > w_sma30，且 w_st_dir = +1 |
| 下降 `down` | 周收 < w_sma10 < w_sma30，且 w_st_dir = −1 |
| 震荡 `flat` | 其他 |

## 4. 信号清单（第一版 18 个，按五类）

「上穿」指昨天 ≤、今天 >；「下穿」反之。

### 趋势 trend

| ID | 方向 | 触发条件 | 强度 |
| --- | --- | --- | --- |
| `T_MA200_UP` | 多 | 收盘上穿 sma200 | 2；当天 `vol_ratio` 的 pct ≥ 0.80 时为 3 |
| `T_MA200_DOWN` | 空 | 收盘下穿 sma200 | 同上 |
| `T_STACK_BULL` | 多 | 今天形成多头排列（收 > sma20 > sma50 > sma200），昨天不是 | 2 |
| `T_STACK_BEAR` | 空 | 今天形成空头排列（收 < sma20 < sma50 < sma200），昨天不是 | 2 |
| `T_MA50_PULLBACK` | 多 | sma50 > sma200 且 sma50 比 10 天前高；前 5 天收盘都在 sma50 上方；今天最低价 ≤ sma50 + 0.5×atr14，收盘仍 > sma50 | 1 |
| `T_MA50_REJECT` | 空 | 上一条的镜像：下降趋势中反弹到 sma50 附近被压回 | 1 |
| `T_ST_FLIP` | 多 / 空 | SuperTrend 方向翻转（`st_dir` 由 −1 变 +1 为多，反之为空） | 2 |
| `W_ST_FLIP` | 多 / 空 | **周线** SuperTrend 翻转（timeframe = W） | 3 |

### 动量 momentum

| ID | 方向 | 触发条件 | 强度 |
| --- | --- | --- | --- |
| `M_RSI_LOW` | 多 | `rsi14` 的 pct 今天 ≤ 0.10，昨天 > 0.10（进入自身超卖区） | 1 |
| `M_RSI_HIGH` | 空 | `rsi14` 的 pct 今天 ≥ 0.90，昨天 < 0.90（进入自身超买区） | 1 |
| `M_MACD_CROSS` | 多 / 空 | macd 上穿 signal 为多，下穿为空 | 1；多头金叉发生在零轴下方、或空头死叉发生在零轴上方时为 2 |
| `M_MACD_DIV` | 多 / 空 | **底背离**：最近两个摆动低点间隔 10–60 根，后一个价格更低，但 macd 更高 → 多；**顶背离**镜像 → 空。在后一个摆动点确认当天触发 | 3 |
| `W_MACD_CROSS` | 多 / 空 | **周线** macd 上穿 / 下穿 signal（timeframe = W） | 2 |

### 波动 volatility

| ID | 方向 | 触发条件 | 强度 |
| --- | --- | --- | --- |
| `V_SQUEEZE_BREAK` | 多 / 空 | 最近 5 天内 `bb_width` 的 pct 曾 ≤ 0.10（收口），今天收盘上穿上轨 → 多；下穿下轨 → 空 | 2 |
| `V_RANGE_EXPAND` | 多 / 空 | `tr_ratio` 的 pct ≥ 0.95（异常大的振幅）；收盘位于当天振幅上 25% → 多，下 25% → 空，中间不触发 | 1 |

### 量能 volume

| ID | 方向 | 触发条件 | 强度 |
| --- | --- | --- | --- |
| `VOL_BREAKOUT` | 多 / 空 | 收盘 > 前 20 日最高价且 `vol_ratio` 的 pct ≥ 0.90 → 多（放量突破）；收盘 < 前 20 日最低价且同样放量 → 空 | 2 |
| `VOL_OBV_DIV` | 多 / 空 | `ret20` 的 pct ≤ 0.10 但 OBV 比 20 天前高 → 多（跌中吸筹）；`ret20` 的 pct ≥ 0.90 但 OBV 比 20 天前低 → 空（涨中出货）。只在条件首次成立的当天触发 | 1 |

### 位置 position

| ID | 方向 | 触发条件 | 强度 |
| --- | --- | --- | --- |
| `P_52W_HIGH` | 多 | 收盘 > `hi_52w`（创 52 周新高），且前 20 天内没有创过 | 2 |
| `P_52W_LOW` | 空 | 收盘 < `lo_52w`，且前 20 天内没有创过 | 2 |
| `P_STRETCH` | 空 / 多 | `ma50_dev` ≥ 2 且其 pct ≥ 0.95 → 空（向上偏离过大）；`ma50_dev` ≤ −2 且 pct ≤ 0.05 → 多（向下偏离过大）。只在条件首次成立的当天触发 | 1 |

> `M_RSI_LOW/HIGH`、`P_STRETCH`、`VOL_OBV_DIV` 是**均值回归**类（逆势），其余是**顺势**类。两类可能在同一只股票上给出相反方向，由第 5 节的打分统一处理。

## 5. 打分与入选

对每只股票、每个交易日 t：

1. **收集**：有效期内的全部信号（见 1 节），同一 ID 只取最近一次。
2. **分方向汇总**：对 d ∈ {多, 空}：
   - `类别数(d)` = 方向为 d 的信号覆盖了几类（五类中）；
   - `基础分(d)` = 这些信号强度之和。
3. **周线同向加分**：周线趋势状态与 d 同向（up↔多、down↔空）时，每个方向为 d 的**日线**信号 +1，最多 +3。
4. **反向扣分**：`综合分(d) = 基础分(d) + 周线加分(d) − 0.5 × 基础分(反方向)`。
5. **定方向**：取综合分较高的方向；若反方向也覆盖 ≥ 2 类，标记「多空分歧」。
6. **入选门槛**：
   - 核心池（AI 主题、期权池、研报覆盖、手动添加）：同向 **≥ 3 类**；
   - 扩展池（其余标普、纳指成分股）：同向 **≥ 4 类**。
7. **共振加分**（P2 接入后生效）：同向期权异动（t 或 t−1）**+3**；近 7 天研报上调评级或目标价 **+2**。
8. **排序**：综合分降序 → 类别数降序 → 近 20 日成交额降序。全部入选结果存入 `opportunities`，界面默认每个方向展示前 10 名。

`opportunities.reasons_json` 存每个信号的 ID、触发日、强度和关键数值（如「RSI 22.4，自身 6% 分位」），供「为什么上榜」展示。

## 6. 推送

- 条件：综合分 **≥ 8**，且期权或研报至少一项与技术面**同向**（决策表：只推高分共振）。
- 每只股票同方向 5 个交易日内只推一次；每天最多推 3 条。
- **P2 接入期权和研报之前不会触发推送**。P1 只把网页推送的通道做好，并发一条测试通知验证。

## 7. 信号历史表现（只展示，不调参）

- 对每个信号 ID，统计过去 2 年中每次触发后 **5 日 / 20 日**的收益：多头用 `收盘(t+h) ÷ 收盘(t) − 1`，空头取相反数。
- 记录：样本数 n、胜率（收益 > 0 的比例）、收益中位数；同时给出同期全部股票、全部交易日的基准值作对照。
- 每周日重算一次，存入 `signal_stats`。数值**只用于展示**，不据此修改任何阈值或强度。

## 8. 实现要求

- **Python（信号，权威实现）**：在计算容器里用 pandas / numpy 实现第 2–5 节。不依赖 pandas-ta 的默认实现细节，公式以本文为准（避免第三方库版本变化导致结果漂移）。
- **TypeScript（图表）**：P2 实现同一套指标，用于前端即时绘图。
- **Golden test**：仓库固定 3 只股票、各 500 根日线作为样本（`tests/fixtures/`），Python 输出全部指标和信号作为基准文件；TS 实现必须与之一致（相对误差 < 1e-9，信号完全一致）。改公式必须同时更新两端和基准文件。
- 移植的开源指标（SuperTrend 等）在 `docs/indicator-licenses.md` 登记来源和许可证。

## 9. 待确认（默认值已写在上面）

1. **均值回归类信号要不要**：RSI 超买超卖、偏离 MA50 过大、OBV 背离属于逆势信号，可能和顺势信号打架。默认保留，强度都只有 1。
2. **有效期 3 天**：让几天内陆续出现的同向信号能叠加成机会。缩短会让机会变少、更「新鲜」，延长会更多但更滞后。
3. **推送门槛 8 分 + 必须有共振**：P2 之前不会推送。如果想 P1 就收到通知，可以加一条临时规则：每天收盘后推送一条「今日上榜 N 只」摘要。
